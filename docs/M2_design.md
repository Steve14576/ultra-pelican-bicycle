# M2 机构与电控方案设计

状态：已冻结（2026-11-27，用户安装 Blender/BambuStudio 并授权 git 维护视为认可）。依据 [PROJECT_BRIEF.md](../PROJECT_BRIEF.md)、[M1_research.md](M1_research.md)；滚动自查见 [completeness_checklist.md](completeness_checklist.md)；定量校验 [scripts/m2_sanity.py](../scripts/m2_sanity.py)。

## 1. 方案一句话

约 40cm 的鹈鹕骑电动辅助轮自行车：手机 WiFi 遥控行走，**单电机驱动后轮，后轮经皮带反带脚踏曲柄，鹈鹕腿为从动连杆——车一跑腿就真蹬**。鹈鹕是软皮塞棉花 + 碳纤骨架的 plush 本体；翅/颈为可摆自锁铰链，蹬车腿为低阻自由铰链。

## 2. 总体布置与尺度（初值，M3 精修）

整车长 ~40cm，轴距 ~24cm，前后轮径 ~10cm；鹈鹕坐高 ~25–30cm，髋关节在曲柄中心上方 ~9cm。后轴两侧助学轮（略小于主轮，倾斜接地），静态稳定。重心低且靠后（电池/电机布于下管与后轴附近）。

## 3. 机构方案

### 3.1 驱动链（单电机）
N20（6V 150rpm 档）→ GT2 皮带 2:1 → 后轴 → 后轮；后轴带轮 → GT2 皮带 1.8:1 → 曲柄轴 → 曲柄 → 脚踏 → 鹈鹕脚 → 腿连杆。

### 3.2 腿部连杆
髋固定于骨架，脚固定于脚踏，大腿+小腿两连杆，膝/踝为从动铰链。曲柄圆驱动脚位置，连杆自身解算膝角。两曲柄臂 180° 相位，腿交替蹬。

### 3.3 转向（评审整改后）
MG90S 宽 22.8mm 不进头管 φ12 孔 → **外置舵机座**（头管后/上管前，M3 热熔螺母固定），经**推杆**连前叉转向臂；**车把**装转向管顶（鹈鹕翅搭握）。头管孔仅走转向管。转向限位由舵机行程 60–120° 限定。三件 CAD/BOM/手册已补（cad/steering.py）。

### 3.4 平衡【已定：助学轮】
后轴两侧助学轮，四轮接地静态稳定。**否决动量轮**（尺寸太大且不可控）、**否决前轮转向自平衡**（舵机速度与精度不够）。

### 3.5 定量校验（m2_sanity.py 实测）
车速 0.31 m/s；后轮 60rpm；曲柄 33rpm；3× 余量折算电机需求 0.27 kg·cm（N20 连续 ~0.5，够）；脚→髋 7–11cm 在腿可达 0–12cm 内，伸展余量 1cm，膝角 71°–133° 不锁死。初版几何死点已修正（髋 9 / 腿各 6cm）。质量/滚阻/N20 扭矩为量级估计，datasheet BOM 阶段核。

## 4. 关节分类设计【已定】

| 类 | 部位 | 行为 | 机构 | 材料 |
| --- | --- | --- | --- | --- |
| A 自锁可摆 | 翅膀、颈 | 摆到哪停到哪（pose 自持） | 摩擦定位铰链：螺丝预紧摩擦面，或合规棘齿/球窝棘位（仿 dummy13） | G-Flex（TPU-PETG 共混）适合合规自锁 |
| B 低阻自由 | 髋/膝/踝、曲柄轴、轮轴 | 自由转动不抱死 | clearance 销轴 + 轴套（PEBA/打印光滑套）；轮轴/曲柄轴用 608ZZ 轴承 | PETG/PEBA + 金属轴承 |

要点：蹬车腿必须 B 类低阻，否则电机堵转/运动卡死。**脚踝**尤其关键——脚固定在随曲柄旋转的脚踏上，踝必须允许脚相对小腿自由转动，否则腿抱死。A 类自锁用于手动摆姿的翅/颈，不参与驱动链。

## 5. 鹈鹕本体设计【已定：软皮 + 棉花 + 碳纤骨架】

- **结构 = 内部碳纤骨架**（PET-CF / PA-CF）：脊柱梁（坐车座）、髋支座、颈根、翅根。全部承载走骨架，符合"不能脆弱"。
- **外观 = 软空心皮 + 塞棉花**：TPU 75A 薄壳（1–2mm）或 G-Flex，空心分件，内塞棉花（采购，用户确认确定可买）。皮不承载，只负责造型与触感。
- **填充方案选择**：棉花填充优先（更软、更轻、plush 感、便宜）；低填充 PEBA 作备选（弹性好但偏重、不够 plush）。
- **混打/拆件**：骨架（CF，刚）与皮（TPU，软）材料不同、角色不同 → **分开打印再装配**，不混一炉。皮壳分件留填棉口，装骨架 → 塞棉 → 闭合（螺丝/卡扣/缝合）。嘴 + 嘴囊（TPU 橙）可与头皮多材料同炉。嘴囊是鹈鹕招牌，M3 造型重点。

## 6. 电控方案

### 6.1 框图
```
2S 7.4V 带保护板电池组 (keyed 插头 + 保险丝)
   |
   +--> DRV8833 VM (7.4V, bulk 电容)
   |        AOUT1/2 --> N20 ; AIN1/AIN2/PWM <-- ESP32
   +--> 5V/3A buck (独立隔离舵机供电)
            +--> ESP32-C3 SuperMini (5V)
            +--> MG90S (5V, 信号 <-- ESP32)
ESP32: WiFi AP "PelicanBike" → 手机大按钮网页 → WebSocket → 电机/舵机 ; 状态 LED
```

### 6.2 供电与安全
成品 2S 7.4V 带保护板组 + 插头充电器（免裸芯焊接，Cindy 插拔）；全系统低压直流，无市电进入。DRV8833 上限 10.8V；N20 额定 6V，固件限 PWM ≤80% + 软启。电池反接保护（keyed 接头 + 保险丝/PTC）。舵机堵转电流大，buck 独立供电 + VM bulk 电容防拉垮 MCU。

### 6.3 遥控
ESP32-C3 自建热点，手机直连无需路由器，网页大按钮（前进/后退/左转/右转/停）。零额外遥控硬件。

### 6.4 PCB【已定：定制载体板】
嘉立创EDA专业版设计 + JLCPCB 打样。模块载体板（through-hole）：SuperMini/DRV8833/buck 母排座 + 带标签 JST/螺钉端子（电池/电机/舵机）+ 开关 + LED。Cindy 只焊少数连接器、插模块，不飞线；模块可单换。不做 SMD 集成（免贴片复杂度，维修友好）。洞洞板仅兜底。

## 7. 仿真与校核决策【已定，先验驱动一次成型】

**硬约束：无打样 / DFM 迭代机会**，只有先验仿真，最终一次性输出交付文件。所有验证前置先验分析，设计按"一次成型"稳健：保守公差、按 FDM 收缩留隙、不依赖物理样件调参。

不做重型 FEA / SPICE（小载荷 + 成熟模块，过度工程）；做以下先验校核（脚本落档）：
1. 运动学扫掠 + 干涉：曲柄一周腿连杆位置/膝角连续，查死点与构件干涉（扩展 m2_sanity.py）；转向扫掠查前轮/叉干涉。
2. 质心 / 稳定：build123d 装配体 mass props 算质心，校核落在助学轮接地 footprint 内。
3. 功率预算：N20 堵转 ~1A + MG90S ~0.7A + ESP32 ~0.4A → 最坏 ~2A；buck 3A 够；DRV8833 单通道 1.2A 连续，N20 堵转接近上限 → 固件软启 + 限 PWM。续航 M3 精算。
4. 公差 / 配合先验分析：轴承压入过盈、轴间隙滑配、热熔螺母孔径、带轮啮合侧隙，按 FDM 收缩（~0.2–0.5mm）与保守间隙定值，出配合公差表（M3）。无样件 → 宁略松不卡死。
5. 关键件手算应力：车架/曲柄/连杆按梁模型手算弯曲/剪切，保守壁厚 sizing（不做全 FEA）。

原"M3 样件验证"项（胎辋互锁强度等）物理不可行 → 改先验保守设计 + 仿真兜底。

## 11. 结构强度原则（不能脆弱）

承载接头螺丝+热熔螺母，热熔胶仅辅助定位防松不承力；层面垂直主应力；壁厚 ≥2.5–3mm，应力处圆角；轴承压入略过盈、轴间隙滑配；车架/曲柄/连杆/骨架用 PETG/PET-CF 不用脆料；电机座后叉加筋；重心低靠后，M3 校核助学轮接地。
