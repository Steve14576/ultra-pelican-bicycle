# Cindy 操作手册 — 鹈鹕自行车

你好 Cindy！这本手册带你把一只会蹬车的鹈鹕自行车做出来。每一步都写清楚了，照着做就行。
**安全第一条**：有大人陪同；电烙铁很烫，只碰手柄；电池不拆不戳不短路；不懂就停下來问。

---

## 0. 工具和材料

工具（家里/现场已有）：拓竹 H3C 打印机、电烙铁+焊锡、万用表、螺丝刀、剪钳。
需要买：**热熔胶枪+胶棒**（见 BOM）。
材料：按 [bom.csv](bom.csv) 清单买。打印件用 U 盘/网络从电脑传给打印机。

买的时候对着清单一样一样买，买齐打勾。电池买"**带保护板成品组+插头充电器**"，不要买裸电芯。

---

## 1. 打印（拓竹 H3C）

1. 电脑打开 BambuStudio，导入 `cad/out/` 里的 STL（按 [bom.md](bom.md) 分盘 P1–P4）。
2. 选 H3C 打印机；材料按盘选：P1=PETG、P2=PEBA、P3=PET-CF、P4=TPU；支撑用"易拆支撑"。
3. 点"切片"→"打印"。一盘一盘打。
4. 打完取件，**2 小时内**把支撑掰掉（久了受潮难掰）。
5. 检查：每个件平整、无裂、孔通畅。软皮（鹈鹕身体）是空心的，留了填棉口。

核对：打印件数量对着 bom.csv 打勾。

---

## 2. 热熔螺母 + 螺丝接头

1. 电烙铁加热，把热熔螺母放进车架/托盘/骨架的预留孔，用烙铁头轻压使其沉入塑料（烫！只碰螺母外围塑料，别碰烙铁）。
2. 冷却后螺母固定。用螺丝把车架各段、托盘、骨架座拧紧。
3. 接头要拧到不晃，但别拧裂塑料。

---

## 3. 焊接载体 PCB

看 [pinout.md](../electronics/pinout.md) 和 [pcb_carrier.md](../electronics/pcb_carrier.md)。

1. 把母排座（J4/J5/J6）、JST 座（J1/J2）、舵机排针 J3、开关 SW1、保险丝 F1、LED+电阻 焊到 PCB 对应位号。
2. 焊点光亮圆润，不连锡。焊完用万用表**蜂鸣档**测：电池座正负极之间**不响**（无短路）才合格。
3. 插上模块：SuperMini→J4，DRV8833→J5，buck→J6。注意方向（对着丝印）。

---

## 4. 接线（全部 keyed 插头，插反插不进）

1. 电池组插头 → J1（经开关/保险丝）。
2. N20 电机 → J2。
3. MG90S 舵机 → J3（信号/5V/地，对着颜色）。
4. 用扎带/热熔胶把线固定，留一点余量，别绷直。
5. **上电前**万用表直流档测电池插头：应读 7.4V 左右（7.0–8.4）。再测 PCB 电池输入无短路。

---

## 5. 机械组装

顺序：车架 → 轮 → 传动 → 腿 → 前叉 → 鹈鹕。

1. **后轮**：608 轴承压入后叉座，8mm 钢轴穿后轮+轴承，E 卡簧限位。装电机带轮（电机轴）+后轴带轮，挂 GT2 带，调电机座滑槽使带张紧（按下约 5mm 挠度）。
2. **曲柄**：轴承压入五通，曲柄轴穿曲柄+轴承，E 卡簧。后轴带轮→曲柄带轮挂第二根 GT2 带张紧。脚踏拧在曲柄端。
3. **腿**：大腿上端接骨架髋孔（M3 销+轴套，能自由转），下端接小腿，小腿接脚踏踝孔。腿要**松快不卡**。
4. **前叉**：转向管插入头管孔，前轴穿前轮+叉片+轴承，E 卡簧。舵机装**外置舵机座**（头管后，螺丝固定），**推杆**两端销连舵机臂与前叉转向臂；**车把**套/拧在转向管顶。
5. **助学轮**：装后轴两侧臂端，略低于主轮（平放时主轮着地、助学轮轻触）。
6. **鹈鹕**：骨架坐车座拧紧；软皮套骨架、**塞棉花**塞饱满、闭合填棉口；嘴囊装头部；翅/颈铰链摆好姿势（自锁会停住）。
7. 电池放托盘扎带固定，PCB 拧在托盘 standoff。

核对：转后轮，曲柄和腿应跟着蹬；转舵机臂前轮应摆；推一下车四轮着地不倒。

---

## 6. 刷固件

1. 电脑装 Arduino IDE + ESP32 板支持（搜 "esp32 by Espressif" 安装）。
2. 打开 `electronics/firmware/pelican_bike.ino`。
3. 选板 "ESP32C3 Dev Module"，USB 连 SuperMini，选对应串口。
4. 点"上传"。等提示完成。
（若上传失败：按住板上 BOOT 键再点上传，或换 USB 线/口。）
或直接用预编译镜像：`esptool.py write_flash 0x0 electronics/firmware/firmware.bin`（合并镜像，起始地址 0x0）。

---

## 7. 遥控测试

1. 开电池开关。手机 WiFi 连 "**PelicanBike**"，密码 `pelican123`。
2. 浏览器打开 `192.168.4.1`。看到大按钮页面。
3. **按住**"前进"车走、腿蹬；松开停。左/右转前轮摆。"停"立即停。
4. 验收清单：直行不偏、腿随车蹬、转向灵、松手即停、推不倒、续航约 2 小时。

## 8. 排障

| 现象 | 查 |
| --- | --- |
| 上电无灯 | 电池电压/开关/保险丝/焊点 |
| 电机不转 | J2 插好? DRV8833 方向? 带太紧卡死? |
| 腿不蹬 | 带松? 曲柄销卡? 腿铰链太紧? |
| 转向不动 | J3 顺序? 舵机臂连杆松? |
| WiFi 连不上 | 开关开? 距离近? 密码 pelican123 |
| 一按就重启 | 舵机堵转拉垮? 测 buck 5V 稳定? |
| 车倒 | 助学轮太低/电池没固定重心高? |

不懂就停下来问大人。做完记得收拾工具、拔电池充电。
